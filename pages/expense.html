填寫報帳內容

每筆費用填寫一行，同一個月的費用可以寫在同一份 Expense Sheet。

點擊圖片可放大

截圖 — 待上傳
Expense Type
報帳類別，選擇符合的項目。
例如：交通費、住宿費、雜費
Date
發票日期。只能填工作日，若發票日期為假日，請選最近的工作日，並在 Description 備註實際日期。
Vendor
廠商名稱，填寫開立發票的公司或店家名稱。
Description
費用說明，請清楚描述用途。若日期需要備註，也在這裡說明。
例如：台北→台中出差交通費
Amount
金額，請與發票金額完全一致。
例如：1,200
提醒：金額填錯，Approved 之後就無法自行修改，請務必確認後再送出。

紙本寄送規範

⚠️ 重要：Expense Sheet 與紙本憑證必須同時寄出，缺一不受理。
1

單據黏貼規範

  • 所有單據黏貼於 A4 白紙上
  • 平鋪黏貼，不可重疊、不可超出紙張邊緣
  • 不可遮蓋金額、日期、統編等重要資訊
  • 每張單據清楚可見，不使用訂書針或迴紋針
  • 在單據上或旁邊寫上申請人姓名
2

寄送內容確認

必須附上
列印好的 Expense Sheet
沒有 Expense Sheet，無法確認申請人與金額，整份退件
必須附上
黏貼好的單據 A4 紙
單據需整齊黏貼，不得散落或重疊
3

寄送資訊

收件人 ／ 地址 ／ 截止期限
請見每月提醒信

常見錯誤

以下是最常見的退件原因，請特別注意。

沒有 Expense Sheet，我們無法知道是誰申請、對應哪些費用，整份退件。

Expense Sheet 和單據必須一起寄出，缺一不受理。

單據散落或只用迴紋針夾，在郵寄過程中容易遺失，也難以核對金額。

請將所有單據平整黏貼於 A4 白紙上再寄出。
